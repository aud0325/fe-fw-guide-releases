    장 다시하기와 세이브 유지 범위

    다른 루트로 잠시 이동하는 것과 지난 장을 다시 시작하는 것은 저장에 미치는 영향이 다릅니다. 중단 진행을 잃는 시점, 장 시작 데이터가 덮어써지는 시점, 되돌아갈 범위를 예시로 확인하세요.

    4. 되돌리기와 인계는 별개의 기능
    5. 지원 올리기를 반복한 경험담과 실행 순서
    6. 지원 유지가 보장하지 않는 것

    중단 진행과 장 시작 기록을 구분하기 i

    네 주인공의 이야기는 루트별로 장 시작 데이터와 장 도중의 중단 데이터를 가집니다. 횃대가 있는 곳에서 네 주인공의 이야기를 선택하는 방으로 돌아갈 수 있습니다. 원문에서 이 장소를 「方尖塔の間」이라고 부릅니다. 그곳에서 다른 주인공으로 전환하는 것만으로는 이전 루트의 중단 진행을 버리는 것이 아닙니다.

    선택현재 진행에 미치는 영향
    다른 주인공의 이야기를 진행각 루트가 중단 데이터를 따로 보유하므로 병행할 수 있습니다.
    같은 루트의 현재 장 또는 과거 장을 처음부터 재개그 루트에서 도중까지 진행한 중단 데이터가 사라집니다. 선택한 장의 시작 상태에서 다시 진행합니다.
    재개한 장을 클리어하여 이후로 진행재플레이한 결과가 이후 장에 반영되면서 기존 장 시작 기록을 덮어쓸 수 있습니다. 뒤쪽 기록을 그대로 보존한 채 새 결과만 합치는 기능은 아닙니다.

    시작하기 전에 목적과 돌아갈 지점 정하기 i

    1. 놓친 대화나 영상을 보기만 하려는 경우에는 먼저 주인공 선택 방의 회상 기능에서 볼 수 있는지 확인하세요. 여기서 볼 수 있다면 장 진행을 다시 시작할 필요가 없습니다.
    2. 동료를 잃기 전으로 돌아가거나, 놓친 영입·아이템·이벤트를 다시 시도하려면 해당 일이 일어나기 전의 장 시작 상태를 확인하세요. 준비할 시간이 부족했던 경우에는 더 이른 장부터 진행해야 할 수 있습니다. 이는 다시 시작할 장을 고르는 판단 기준이며, 영입 조건 자체가 없어지는 것은 아닙니다.
    3. 현재 루트의 중단 진행에서 포기하게 될 작업을 먼저 확인하세요. 그 장을 시작한 뒤 얻은 진행을 그대로 유지해야 한다면, 장 재개를 확정하지 마세요. 다른 루트에서 잠시 플레이하는 선택과 구분해야 합니다.
    4. 장 선택 기능에서 원하는 시작 지점을 골라 재개합니다. 과거 상황만 확인한 뒤 돌아갈 계획이라면 기존의 뒤쪽 장 시작 기록이 남아 있는지 확인하고, 재플레이 결과로 덮어쓰는 클리어를 진행하기 전에 돌아갈지 결정하세요.

    예시: 5장 도중에 4장을 다시 시작한다면 i

    Nintendo DREAM WEB은 레다의 5장 중단 데이터와 4장 시작 상태를 비교하는 예를 제시합니다. 핵심은 「5장으로 돌아갈 수 있다」가 「5장에서 하던 일을 그대로 이어갈 수 있다」는 뜻은 아니라는 점입니다.

    1. 5장 도중에서 주인공 선택 방으로 돌아온 상태에는 5장 중단 데이터와 기존 5장 시작 데이터가 구분되어 있습니다.
    2. 4장을 다시 시작하면 5장 도중의 중단 진행은 사라집니다. 반면 기존 5장 시작 데이터는 이 선택만으로 없어지지 않습니다.
    3. 재클리어로 덮어쓰기 전에는 남아 있는 5장 시작 데이터를 선택해 돌아갈 수 있습니다. 다만 돌아가는 지점은 5장 시작이며, 이전에 5장 도중까지 해 둔 행동을 되살리는 것은 아닙니다. 돌아가려면 다시 횃대가 있는 곳에서 주인공 선택 방으로 나와 장을 선택합니다.
    4. 반대로 4장을 다시 클리어하여 새 결과를 이후로 이어 가면, 이후 장 시작 데이터의 덮어쓰기가 발생합니다. 옛 5장 시작 상태를 남겨 두고 싶다면 이를 단순한 이벤트 감상과 같은 행동으로 취급하지 마세요.

    되돌리기와 인계는 별개의 기능 i

    장 다시하기는 동료 로스트, 영입 기한, 놓친 아이템이나 이벤트, 마음에 들지 않는 육성 결과를 다시 시도할 출발점을 제공합니다. 그러나 직전 행동 하나만 취소하거나 원하는 시각의 저장 슬롯을 복제하는 방식은 아닙니다. 원하는 상황보다 이전 장 시작점까지 돌아가 그 사이의 진행을 다시 해야 할 수 있습니다.

    다른 루트로 무엇이 인계되는지와, 같은 루트의 어느 시점으로 돌아갈 수 있는지는 서로 다른 문제입니다. 일부 요소가 유지된다는 인계 안내를 중단 진행까지 복구된다는 뜻으로 받아들이지 마세요. 이 안내의 저장 동작은 Nintendo DREAM WEB의 설명을 정리한 것으로, 삭제된 중단 데이터를 별도로 되살리는 방법은 확인하지 못했습니다.

    지원 올리기를 반복한 경험담과 실행 순서 iiii

    1부를 진행하던 커뮤니티 작성자는 식사로 지원을 올리고 장을 다시 시작했을 때, 장 진행은 되돌아가지만 지원은 남았다고 보고했습니다. 다른 게시글은 선물과 비둘기 교류로 얻은 지원도 남았다고 덧붙입니다. 아래는 그 경험담을 정리한 순서이며, 모든 루트·장·버전에서 재현한 방법은 아닙니다.

    시도하기 전에 이번 장 도중에 얻은 진행을 포기해도 되는지 먼저 판단하세요. 지원이 남는다는 보고는 중단 데이터도 남는다는 뜻이 아닙니다. 현재 육성·영입·진행 결과를 지켜야 한다면 반복을 시작하지 않는 편이 낫습니다.

    1. 지원이 필요한 상대를 여관 식사에 초대해 지원을 올립니다. 아직 한 번도 선물하지 않은 상대라면 먼저 선물을 줘야 식사에 초대할 수 있습니다. 대상이 외출 중이면 초대할 수 없는 경우도 있습니다.
    2. 작성자는 개별 행동으로 다음 주까지 진행한 뒤 식사를 반복했습니다. 이 과정에서 실제 주간 일정이 진행되므로, 본편을 그대로 이어 갈 계획과 섞어 생각하지 마세요.
    3. 장 메인 진행을 마치기 전에 시스템 메뉴의 장 다시 시작하기를 선택한 것이 보고된 방법입니다. 이는 앱 종료나 일반적인 불러오기로 식사만 취소하는 방법이 아닙니다.
    4. 재시작 후 해당 캐릭터 사이의 지원과 장 시작 상태를 비교하세요. 원하는 지원이 유지되지 않았다면 반복을 중단하세요. 차이가 나는 이유나 확정 재현 조건은 이 자료로 판단할 수 없습니다.

    지원 유지가 보장하지 않는 것 iiii

    • Nintendo DREAM WEB은 지원 레벨의 인계를 별도로 설명합니다. 이는 지원이 다른 진행 데이터와 다르게 취급된다는 설명을 뒷받침하지만, 커뮤니티의 식사 반복 절차나 매번 같은 절약 효과까지 검증한 것은 아닙니다. 정상 설계인지 버그인지도 여기서 확정하지 않습니다.
    • 지원이 높아도 즉시 전원 영입이 가능해지는 것은 아닙니다. 현재 주인공과 대상 사이의 지원 외에 명성, 요구품·협상, 등장 시기와 진행 조건을 따로 충족해야 합니다. 지원 대화 수집과 실제 영입 완료도 구분하세요.
    • 식사에 쓴 골드를 아낄 수 있다는 것은 원 작성자의 설명입니다. 모든 소비 재료·돈·다른 보상이 원하는 상태로 복구된다는 보장은 아닙니다. 특히 장 재개로 사라진 중단 진행을 지원 유지 효과로 되살릴 수는 없으며, 재클리어로 뒤쪽 장 시작 기록까지 덮어쓰는 일은 별도로 주의해야 합니다.
